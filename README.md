# L7 MATRIX Web V1.1 — SA Bridge Test

This version adds a Safari bookmarklet bridge for testing the existing SA Reader on iPhone.

Important:
- The L7 website itself cannot directly inspect a different website's DOM because of browser same-origin isolation.
- The bridge must be explicitly activated by the user on the already-open SA page.
- No credentials, cookies, tokens, or automatic betting actions are used.
- If the short loader is blocked by the platform's CSP, try the full inline bookmarklet in L7_SA_BOOKMARKLET.txt.
- This is a technical test, not the final production architecture.
